# Phase 26-01 Plan — 계산기/제휴 전환 강화

## Goal
계산기 결과와 단지 상세 문맥을 실제 제휴 전환 흐름과 더 강하게 연결한다.

## Scope

### 1. 계산기 결과 구간 전환 강화
- LoanCalculatorTab의 결과 구간을 `정보 제공 → 절감 인식 → CTA 클릭` 흐름으로 정리
- 기본 CPA 배너 외에 계산 근거 문구/절감 유도 문구를 명확히 유지
- 클릭 이벤트 명을 전환 분석 관점에서 더 읽기 쉽게 정리할지 검토

### 2. 단지 상세 → 계산기 전환 강화
- MiniLoanCalculator 상단/하단 CTA 문구 점검
- 단지 가격 문맥(`최근 거래가`, `전세가율`, `최고가 대비`)과 계산기 이동 동선을 더 자연스럽게 연결
- 필요시 계산기 deep-link 쿼리(principal/tab)를 통일

### 3. 추적 포인트 점검
- 계산기 진입
- 계산 실행
- CPA 클릭
- 단지 상세에서 계산기 진입

- `src/lib/analytics/events.ts`

## Success Criteria
1. 계산기 결과 직후 CTA 구조가 더 명확해진다
2. 단지 상세에서 계산기로 유입되는 경로가 사용자의 현재 문맥과 자연스럽게 이어진다
3. 전환 관련 핵심 클릭 이벤트를 최소한 코드 레벨에서 추적할 수 있다

## Notes
- 현재 코드베이스에는 `CpaBanner`, `trackCalculate`, `MiniLoanCalculator` 등 기반이 이미 존재함
- Phase 26은 신규 구축보다는 기존 구성요소를 실제 매출 흐름에 맞게 연결/정리하는 성격이 강함
