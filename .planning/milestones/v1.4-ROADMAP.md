# Roadmap: 돈줍 v1.4 — 전환 최적화 + 리텐션 기초

**Milestone Goal:** 데이터 중심 서비스 위에 광고/제휴/탐색/개인화 레이어를 추가해 재방문과 수익을 동시에 만든다.

---

## Phase 25: 광고/추적 기반 구축
**Goal**: 수익화와 분석을 위한 기본 인프라를 안전하게 적용한다.
**Requirements**: MON-01, MON-02
**Success Criteria**:
1. 레이아웃에 전역 광고/분석 스크립트가 환경변수 기반으로 안전하게 적용된다
2. 메인/상세/리포트/금리 페이지에 최소 1개 이상의 합리적 광고 슬롯이 삽입된다
3. 모바일/데스크톱에서 광고 밀도가 과하지 않도록 레이아웃이 유지된다

## Phase 26: 계산기/제휴 전환 강화
**Goal**: 금리 계산기와 제휴 CTA를 실제 매출 경로로 연결한다.
**Requirements**: MON-03, MON-04, FUN-04
**Success Criteria**:
1. 계산기 결과 직후 실제 CPA CTA 또는 동등한 제휴 이동 경로가 동작한다
2. 단지 상세에서 계산기로 들어가는 CTA가 가격/상황 문맥과 함께 강화된다
3. 주요 CTA 클릭이 최소 1개 분석 경로에 기록된다

## Phase 27: 탐색 퍼널 최적화
**Goal**: 홈/리포트 유입 사용자를 더 많은 내부 페이지로 순환시킨다.
**Requirements**: FUN-01, FUN-02, FUN-03
**Success Criteria**:
1. 메인 폭락/신고가 카드가 단지 상세로 자연스럽게 연결된다
2. 메인에 탐색 CTA(검색, 내 아파트 찾기 등)가 명확히 노출된다
3. 데일리 리포트에서 관련 단지/지역 이동 링크가 강화된다

## Phase 28: 리텐션 MVP
**Goal**: 사용자가 다시 들어올 이유를 만드는 최소 개인화 기능을 제공한다.
**Requirements**: RET-01, RET-02, RET-04
**Success Criteria**:
1. 관심 단지 저장/해제가 로그인 사용자 기준으로 동작한다
2. 최근 본 단지 또는 비교 목록이 유지된다
3. 홈/프로필에서 저장한 단지나 최근 본 단지로 다시 진입 가능하다

## Phase 29: 알림/실험/분석 고도화
**Goal**: 반복 방문과 전환 실험의 기반 데이터를 확보한다.
**Requirements**: RET-03, ANA-01, ANA-02, ANA-03
**Success Criteria**:
1. 관심 단지 기반 기본 알림 조건이 정의되고 저장된다
2. 핵심 이벤트(광고/CTA/계산기/저장)가 분석 도구 또는 서버 로그에서 확인된다
3. CTA 카피 또는 위치에 대해 최소 1개의 실험 포인트가 마련된다

---

## Recommended Execution Order

1. **Phase 25** — 돈 버는 기반과 측정 기반을 먼저 깐다
2. **Phase 26** — 가장 직접적인 매출 경로인 계산기/CPA를 연결한다
3. **Phase 27** — 유입 사용자를 내부 탐색으로 더 순환시킨다
4. **Phase 28** — 관심단지/최근본단지로 재방문 루프를 만든다
5. **Phase 29** — 알림과 실험으로 성장 최적화를 시작한다

## KPI Suggestions

- 페이지당 평균 PV 상승
- 계산기 진입률 상승
- 계산기 → 제휴 CTA 클릭률
- 저장한 관심단지 수
- 재방문율 (7일 / 30일)
- 데일리 리포트 → 단지 상세 이동률
