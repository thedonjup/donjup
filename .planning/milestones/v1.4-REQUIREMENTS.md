# Requirements: 돈줍 v1.4

**Defined:** 2026-04-07
**Core Value:** 유입된 사용자를 더 오래 머물게 하고, 다시 방문하게 만들며, 광고/제휴/알림을 통해 수익으로 연결한다.

## v1.4 Requirements

Requirements for 전환 최적화 + 리텐션 기초. Each maps to roadmap phases.

### 수익화 (MONETIZATION)

- [ ] **MON-01**: 메인/상세/리포트/금리 페이지에 광고 슬롯이 정책 범위 내에서 일관되게 배치된다
- [ ] **MON-02**: 전역 애드센스/트래픽 추적 스크립트가 안전하게 로드된다
- [ ] **MON-03**: 대출 계산기 결과 직후 CPA CTA가 실제 제휴 링크 또는 전환 경로와 연결된다
- [ ] **MON-04**: 단지 상세/금리 페이지에서 계산기 및 제휴 전환 동선이 자연스럽게 이어진다

### 전환 퍼널 (FUNNEL)

- [ ] **FUN-01**: 메인 폭락/신고가 카드에서 단지 상세로 바로 이동할 수 있다
- [ ] **FUN-02**: 메인에 ‘내 아파트 검색’ 또는 동등한 탐색 CTA가 명확히 노출된다
- [ ] **FUN-03**: 데일리 리포트에서 관련 단지/지역으로 이어지는 내부 링크가 강화된다
- [ ] **FUN-04**: 계산기/상세/리포트 주요 CTA 클릭 이벤트가 추적된다

### 리텐션/개인화 (RETENTION)

- [ ] **RET-01**: 로그인 사용자가 관심 단지를 저장/해제할 수 있다
- [ ] **RET-02**: 최근 본 단지 또는 비교 목록 중 최소 1개가 유지되어 재방문 진입점이 된다
- [ ] **RET-03**: 관심 단지 기반의 기본 알림 조건(신고가/폭락/가격변동 중 최소 1개)이 정의되고 저장된다
- [ ] **RET-04**: 홈 또는 프로필에서 저장한 단지/최근 본 단지를 다시 진입할 수 있다

### 운영 데이터/실험 (ANALYTICS)

- [ ] **ANA-01**: 광고 노출, CTA 클릭, 계산기 진입, 관심단지 저장 등 핵심 이벤트가 추적된다
- [ ] **ANA-02**: 페이지별 주요 전환 지표를 최소한 로그/대시보드/분석도구 중 하나에서 확인할 수 있다
- [ ] **ANA-03**: 고정 문구가 아닌 최소 1개 CTA 구간에서 카피 실험 또는 위치 실험이 가능하다

## Out of Scope

| Feature | Reason |
|---------|--------|
| AI 가격 예측 고도화 | v1.4에서는 수익화/리텐션 기초가 우선 |
| 멀티 부동산 유형 대확장 | v3 마스터플랜 주제이며 범위가 큼 |
| 대규모 커뮤니티 기능 | 댓글 이상의 소셜 기능은 운영 부담 큼 |
| 완전한 유료 구독 출시 | 먼저 무료 서비스 전환 구조 검증 필요 |
